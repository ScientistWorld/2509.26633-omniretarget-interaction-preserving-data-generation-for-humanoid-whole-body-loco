# Overview

OmniRetarget addresses humanoid motion retargeting for object and terrain interaction. The paper argues that preserving interaction geometry and enforcing hard kinematic constraints produces higher-quality reference trajectories than keypoint-only retargeting, reducing penetration and foot skating while maintaining contacts.

This workspace packages a scaled reproduction of the core kinematic claim. It provides procedural interaction tasks, a keypoint IK baseline, an OmniRetarget-style interaction-mesh optimizer, and a reusable evaluator for the paper's main kinematic metrics.

---

# Problem Definition

The task is kinematic retargeting for humanoid whole-body interaction. Given a time series of human keypoints and scene geometry, produce a time series of robot configurations whose forward-kinematic keypoints preserve the demonstrated interaction while respecting robot feasibility.

The benchmark contains two scaled interaction settings:

- `object_carry`: a biped carries a box while walking. Hand-object contact should be preserved without pushing non-contact body parts into the object.
- `terrain_step`: a biped traverses a ramped step-like terrain and uses hand support on the elevated platform surface. Foot and hand terrain contacts should be preserved without terrain penetration or foot skating.

Inputs are stored as JSON task files generated by [data/synthetic_locomotion.py](/home/user/data/synthetic_locomotion.py). Each task includes source keypoints, object surface samples, terrain samples, contact labels, and timestep duration. A valid method writes retargeted robot keypoints and configurations in the artifact format consumed by [eval/evaluate_retargeting.py](/home/user/eval/evaluate_retargeting.py).

---

# Method

OmniRetarget builds an interaction mesh from body keypoints plus dense object and terrain samples. It computes uniform-weight Laplacian coordinates over Delaunay mesh neighbors and retargets each frame by minimizing Laplacian deformation between source and target meshes.

For each frame, the implementation solves for a planar humanoid configuration with:

- Laplacian deformation objective over robot, object, and terrain mesh vertices.
- Temporal smoothness from the previous frame's configuration.
- Joint bounds and per-frame velocity bounds.
- Terrain and object non-penetration constraints.
- Stance-foot equality constraints when source foot horizontal velocity is low.
- Warm start from the previous optimized frame.

The paper uses a custom sequential SOCP solver with Drake automatic differentiation for Unitree G1/H1/Booster models. This reproduction uses SciPy SLSQP on a smaller planar humanoid benchmark while preserving the paper's computational formulation: interaction mesh Laplacian retargeting with hard kinematic constraints. The baseline is a keypoint-position IK method from the PHC/GMR objective family, which lacks interaction mesh preservation and hard contact constraints.

---

# Evaluation

Evaluation reads candidate artifacts from `checkpoints/retargeting/*.json` and writes `scoring/scores.json`. It does not import from any solution implementation. The evaluator also writes `scoring/diagnostics.json` with every artifact it scored.

Metrics measure kinematic interaction quality:

- `penetration_duration`: fraction of frames with robot-object or robot-terrain penetration.
- `max_penetration_cm`: maximum penetration depth in centimeters.
- `foot_skating_duration`: fraction of desired stance-foot contacts where the robot foot moves above the tolerance.
- `max_foot_skating_cm_s`: maximum stance-foot speed in centimeters per second.
- `contact_preservation`: fraction of desired hand-object or hand-terrain contacts that remain close enough to contact.

A successful candidate should reduce physical artifacts while preserving task contacts. Higher-quality results improve the same metrics across both interaction settings.
