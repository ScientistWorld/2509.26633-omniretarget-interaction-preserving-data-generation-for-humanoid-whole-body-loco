# Design notes (current gym, after iteration 12 hardening)

- **Scenes:** every instance has `source_scene` (human scale), `nominal_scene` (direct scaling by alpha = h_robot/h_human about the ground below the initial pelvis; object keeps its size) and `target_scene` (= nominal, or an augmented copy). Object task: box carried overhead up a ramp onto a platform; terrain task: ramp + platform + bracing a hand on a column.
- **Split:** public train = 60 procedurally generated demonstrations in `data/tasks/train/` (20 per experiment, generator `data/task_generator.py`, public seed). Hidden test = 180 demonstrations (60 per experiment) generated in memory at test time by `eval/test/hidden_tasks.py` (self-contained copy of the generator, private seed). Same distribution, disjoint draws.
- **Method interface:** every `scripts/retargeters/<name>.sh <input_dir> <output_dir>` is discovered and run by both evaluators on fresh temporary copies of the inputs; outputs are `{"q": [...]}` per instance.
- **Scoring:** `eval/train/scoring_core.py` and `eval/test/scoring_core.py` (independent copies) recompute all eight metrics from `q` with their own robot model and scene geometry. Validity gate (shape, finiteness, joint limits, per-frame velocity limits, every instance present, exit code, counted CPU budget of 6 CPU s per instance, no-progress hang guard; no wall-clock limit); a failed run gets the worst value of every metric in every experiment. Methods run single-threaded (BLAS/OpenMP).
- **Experiments:** object (0.35), terrain (0.35), augmented scene (0.30). See `scoring/EXPERIMENTS.md`, `briefing/evaluation.md`.
- **Audit:** `HARDENING.md` and `redteam/hardening/` (exploration, resumable harness, variants, shortcut submissions, results; iteration-11 results in `results_iter11/`).
