# Problem Definition

The task is kinematic retargeting for humanoid whole-body interaction. Given a time series of human keypoints and scene geometry, produce a time series of robot configurations whose forward-kinematic keypoints preserve the demonstrated interaction while respecting robot feasibility.

The benchmark contains two scaled interaction settings:

- `object_carry`: a biped carries a box while walking. Hand-object contact should be preserved without pushing non-contact body parts into the object.
- `terrain_step`: a biped traverses a step-like terrain and uses hand support on the elevated surface. Foot and hand terrain contacts should be preserved without terrain penetration or foot skating.

Inputs are stored as JSON task files generated by [data/synthetic_locomotion.py](/home/user/data/synthetic_locomotion.py). Each task includes source keypoints, object surface samples, terrain samples, contact labels, and timestep duration. A valid method writes retargeted robot keypoints and configurations in the artifact format consumed by [eval/evaluate_retargeting.py](/home/user/eval/evaluate_retargeting.py).
